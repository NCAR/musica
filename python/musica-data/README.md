# musica-data
[![PyPI](https://img.shields.io/pypi/v/musica-data.svg)](https://pypi.org/project/musica-data/)

Configuration and data files for the [musica](https://pypi.org/project/musica/) Python package.

The files are the `configs/` directory of the [MUSICA repository](https://github.com/NCAR/musica).
